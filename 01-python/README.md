# Stage 1 — Python for GenAI/FDE

The objective is not to become a Python language specialist. It is to become sufficiently fluent to build, debug and discuss production GenAI services and to code comfortably during interviews.

## 1A — Foundations

Topics:
1. Python mental model and syntax
2. collections and mutability
3. functions and scope
4. comprehensions
5. exceptions
6. modules and packages
7. classes, dataclasses and OOP
8. typing
9. JSON/files
10. mini application
11. interview drill

Code in this stage should be written as part of active learning rather than pre-generated as portfolio filler.

## 1B — Production Python

Topics:
- HTTP
- Pydantic
- async/await
- FastAPI
- configuration
- logging
- pytest
- packaging

## Completion criteria

Stage 1 is complete when Python can be used to implement a small API/service without step-by-step assistance and core Python/FastAPI decisions can be explained under interview questioning.
