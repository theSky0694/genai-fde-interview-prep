# GenAI / FDE Interview Prep

A focused, evidence-based preparation repository for transitioning from senior integration engineering into Generative AI / Forward Deployed Engineering roles.

## Current status

**Stage:** 1 — Python for GenAI/FDE  
**Started:** 22 September 2026  
**Target:** Interview-ready by March 2027  
**Current checkpoint:** 1A — Python foundations

## How this repository works

**Learn → Implement → Review → Improve → Push → Interview Drill → Measure**

Portfolio code should be explainable in an interview. Reported interview experiences are used to continuously test and reweight the preparation plan.
